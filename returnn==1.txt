## 关键语句解析：`return n == 1;`

### 1. 运算符含义
- `==` 是比较运算符，用来判断左右两边是否相等。
- 表达式 `n == 1` 会返回一个布尔值：
  - 如果 `n` 等于 1 → 结果为 `true`
  - 如果 `n` 不等于 1 → 结果为 `false`

### 2. 返回逻辑
- `return n == 1;` 就是直接把这个布尔结果返回给调用者。
- 在丑数问题中，经过不断除以 2、3、5 后：
  - 如果最后剩下的数是 1 → 说明只由 2、3、5 构成，是丑数。
  - 如果不是 1 → 说明还有其他质因数，不是丑数。

### 3. 等价写法
```cpp
if (n == 1) return true;
else return false;
